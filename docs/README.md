# Cobee 하니스 문서

이 문서는 에이전트와 개발자가 작업 위치와 검증 방법을 찾는 지도이다.
탈퇴 구현의 확인 기준일은 2026-10-31이다. 그 밖의 기존 검증 날짜는 각 문서에 적는다.
실제 동작과 설정의 최종 근거는 원본 코드이다.

1. [공통 작업 규칙](../AGENTS.md)을 읽는다.

4. 해당 원본 코드와 설정을 대조한 뒤 작업한다.

## 정보의 상태

- **코드 확인**: 원본 파일에서 구조와 선언을 확인했다. 실행 성공을 뜻하지 않는다.
- **실행 확인**: 적힌 환경과 명령에서 결과를 확인했다. 확인 범위와 날짜를 함께 적는다.
- **확인 필요**: 코드 사이의 불일치나 아직 실행하지 않은 경로이다.

현재 실행 근거는 [검증 기록](verification.md#마지막-검증-기록)에 있다.
동기화 HTTP 전체 흐름과 모델 학습은 별도 검증 대상이다.
RAG 설계와 추천 이벤트 계약은 제안이다.
MSA 탈퇴 개선은 구현과 로컬 검증을 완료했다. 결과는 [TDD 비교 기록](../diagnostics/2026-10-31/withdrawal-tdd/README.md)에 있다. 운영 배포는 수행하지 않았다.

## 실행 환경 안내

- MSA 버전과 실행 전제는 [MSA 작업 규칙](../cobee-msa/AGENTS.md)을 본다.
- ML 설치와 로컬 실행은 [ML README](../cobee-ml/README.md)를 본다.
- 테스트와 정적 검사 명령의 공통 기준은 [검증 기준](verification.md)이다.
- 새 문서는 이 목차에서 연결한다. 같은 사실을 여러 문서에 길게 복사하지 않는다.

## Graphify

Graphify는 두 패키지를 탐색하는 정적 지도이다.
사용법과 수동 갱신 순서는 [공통 규칙의 Graphify 절](../AGENTS.md#graphify)을 따른다.
P1 변경 후 일부 소스 해시가 달라졌다. 관련 관계는 현재 코드와 다시 대조한다.
